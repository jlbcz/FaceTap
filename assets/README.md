# Assets

This folder holds public project assets such as:

- Logos and icons that the project is allowed to publish
- Exported diagrams
- Images used in the documentation

## Rules

- Add only material the project owns or has permission to publish. An institution's logo may need its approval.
- Do not store photos of real people, face samples, exports of attendance data, or documents with personal information here.
- Prefer SVG for logos and diagrams, and PNG for anything else.
- Use lowercase filenames with hyphens, such as `facetap-logo.svg`.

Screenshots of the application go in [`../screenshots/`](../screenshots/README.md) instead.
